# 初中英语散步听

一个为「边走边听」设计的英语听力网页应用（PWA）。手机浏览器打开即用，可添加到主屏幕、离线缓存。

**在线地址**：https://x13502239474-oss.github.io/walk-english-podcast/

## 两个板块

### 1. 单词播客（32 集，约 8.7 小时）

内容来自新东方《初中英语词汇词根+联想记忆法》，共 **1812 个词条**，按原书 32 个 Word List 分集，每集约 16 分钟。

每集节奏：单词慢速读两遍 → 中文释义 + 例句译文 → 英文例句 → 2.2 秒留白回想。

### 2. 英语节目（100 集，全英文情景对话）

全程英文音频（无中文旁白），题材取自初中课标话题与日常生活场景，每集 3–7 分钟，双场景剧情式对话，覆盖 15 大课标话题。

> 第 21–100 集主题：日常作息、家庭、校园补充、饮食健康、购物消费、天气季节、兴趣运动、交通出行、旅行假期、健康就医、环境自然、节日文化、科技媒体、情感成长、未来理想。完整清单见仓库根目录 `选题清单.md`。

单集结构：冷开场 → 主持人引入 → 情景对话 × 2 → **慢速跟读**（整段对话降速重放）→ 例句领读 → 重点表达 → 口语任务 → 结尾。

- **音频全程英文**，三个固定声部（主持人 Jenny、男角色 Andrew / Christopher、女角色 Ava）
- **中文翻译不在音频里**：播放页点「翻译」展开整集中英对照文稿，当前句自动高亮

## 功能

- **每日学习统计**：今日学习分钟数、连续天数、累计小时，附近 7 天柱状图（只统计真正播放的时长，拖动进度条不虚增）
- 进度条可拖动跳转，带时间气泡，跳转时显示缓冲状态
- 0.8×–1.5× 倍速、连播、10/30/45 分钟定时关闭
- 锁屏后台播放，耳机线控切上一句／下一句
- 当前句子实时显示，整集字幕可展开中英对照
- 播放进度自动记忆
- 单集离线下载，无网络也能听 

## 本地运行

```bash
cd podcast
python -m http.server 8765
# 打开 http://localhost:8765
```

Windows 下双击 `启动.bat` 会自动起服务并用 Chrome 打开；也可以直接双击 `podcast.html`（单文件版，数据已内嵌，不需要服务器）。

## 目录结构

```
podcast/
├── index.html            发布入口（数据已内嵌，构建产物）
├── index.src.html        源模板，改样式／逻辑改这个
├── podcast.html          单文件版（与 index.html 内容相同，供本地双击）
├── sw.js                 Service Worker，负责离线缓存
├── manifest.webmanifest  PWA 配置
├── icon.svg              图标
├── data/
│   ├── data.js           内联数据（构建时注入 HTML）
│   ├── words.json        单词数据（1812 词）
│   ├── episodes.json     单词板块分集元数据
│   └── talks.json        节目板块分集元数据与中英字幕
└── audio/
    ├── ep01..ep32.mp3    单词播客音频
    └── talk01..talk100.mp3 英语节目音频
```

修改前端后执行 `python make_standalone.py` 重新生成 `index.html` 等内嵌版，**不要直接改 `index.html`**（会被覆盖）。

## 重新生成

音频由微软 Edge TTS 合成（`en-US-JennyNeural` 主持、`en-US-AndrewNeural` / `en-US-AvaNeural` / `en-US-ChristopherNeural` 角色，中文 `zh-CN-XiaoxiaoNeural`）。

```bash
pip install edge-tts
python parse_words.py     # 从 epub 提取单词，生成 data/words.json
python build_podcast.py   # 生成单词板块音频
python build_talks.py     # 生成节目板块音频（脚本在 talk_scripts.py + talk_scripts_extra.py）
python make_datajs.py     # 生成离线数据与元数据
```

需要 ffmpeg 参与音频拼接。
